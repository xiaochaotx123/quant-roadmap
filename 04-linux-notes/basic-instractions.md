## cd 
cd 是 change directory, 即切当前工作目录


绝对路径：从根目录`/`写起的完整地址
相对路径：从当前工作目录写起的地址

现在在家目录`/home/rover`，敲了：
```python
cd home
```   
会报错，因为`没有哪个文件或者目录`  

因为`home`是相对路径，系统理解成 **"当前目录下的home"**，也就是去找`/home/rover/home`，但是没有，所以报错  

如果是敲：
```python
cd /home
```
就成功了，因为`/home`是绝对路径，系统会从根目录开始找，找到`/home`目录，所以成功了  


#### ~ 和 /
`~` 表示家目录，即当前用户的家目录，例如`/home/rover`，也可以写成`~`，例如`cd ~`，表示切换到当前用户的家目录。  

`/` 表示根目录，整个文件系统的最顶层




## pwd
pwd 的意思是 print working directory，即打印当前工作目录
pwd 不改变任何东西，只是告诉当前的路径  


## ls
ls 的意思是 list, 即列出当前目录下的文件和目录
ls 不改变任何东西，只是告诉当前目录下的文件和目录  

|命令|显示什么|
|-|-| 
|ls|跳过所有以 . 开头的文件|
|ls -a|全部显示，-a = --all|
|ls -1a|全部显示，并带权限、大小、时间（最常用）|
